# 除螨喷雾直播间：标题字体专用规范

## 适用范围

仅在策划、产品资料或用户明确说明主产品为 `除螨喷雾`，或任务名称明确为 `除螨喷雾直播间` 时启用本规范。

不要把本规范扩大到：

- 普通周年庆直播间；
- 其他清洁、消毒或母婴产品；
- 除螨仪、吸尘器、床品或其他非喷雾类除螨产品；
- 仅在文案中偶然出现“除螨”，但主产品并非除螨喷雾的项目。

用户最新的明确修改优先于本规范。商业标题、品牌名及标点必须逐字来自当前策划，不得把示例文案写死到后续项目。

本文件只控制主标题字体风格，不控制标题区域大小、位置、换行方式、配色、背景色块、材质、描边、投影、光效、底板或装饰。上述内容全部跟随当前策划、风格参考和用户要求。

## 1. 主标题字体边界

主标题使用有定制感的现代中文展示黑体，风格中性、稳健、有力度但不粗暴：

- 字重以中粗至偏粗为准，视觉约等于 `600–750`；不得纤细，也不得用超黑体压满字腔。
- 横竖笔画要有足够体量，字面舒展，内白开阔；避免过度窄长、尖瘦或高对比笔画。
- 收笔可以轻微圆润或利落削切，但只能是柔和、克制的定制处理；不得出现刀片感、机甲感和过多尖角。
- 可通过字面宽窄变化、局部笔画连接、轻微错位、一处识别性切角或克制的字形重构体现设计感，不依赖夸张变形。
- 标题整体要清晰易读，不能为了造型破坏汉字结构、品牌名或商业文案。
- 不得用描边、投影、金属挤出或其他字效掩盖字体本身缺乏设计的问题。

必须避免：

- 纤细时装体、高对比衬线体、细长曲线、书法钩挑和长拖尾造成的过度女性化；
- 超宽超黑、硬切割、斜刀口、重金属挤出造成的过度硬朗；
- 泡泡字、圆胖童趣字、卡通描边和果冻膨胀造成的幼态；
- 默认办公黑体、传统牌匾字、宋体或政务庆典式字形；
- 仅靠放大和加粗、没有主次与结构设计的平铺标题。

## 2. Phase 1 提示词必加块

当本规范被触发时，把下面内容加入 Phase 1 的 `【顶部标题系统】`，并替换方括号中的真实策划内容：

```text
本项目为除螨喷雾直播间，仅对主标题字体启用专用要求。主标题为[准确标题]，使用中粗至偏粗、字面舒展、内白开阔的现代中文展示黑体，气质中性成熟、有设计感但不粗暴。可通过字面宽窄变化、局部笔画连接、轻微错位或一处克制切角形成定制感。禁止纤细时装体、细长拖尾、高对比笔画、泡泡幼态字、刀锋机甲切角、超宽超黑字形、传统牌匾字、宋体和默认办公字体。不得用夸张描边、投影或挤出替代字体设计。标题区域、位置、换行、配色、材质、底板、光效和装饰全部按照当前策划与风格参考，不受本专用字体规则限制。
```

## 3. 专用标题字体 QA 与一票否决

展示 Phase 1 候选前逐项检查：

- [ ] 已确认主产品确实是除螨喷雾，本规范没有误触发；
- [ ] 标题字重处于中粗至偏粗，既不纤细女性化，也不超黑笨重；
- [ ] 字形有定制感，但不硬朗、不幼态、不传统牌匾化；
- [ ] 字体本身具备设计感，不是默认字体叠加夸张字效；
- [ ] 主标题汉字结构、品牌名和标点全部准确可读；
- [ ] 本规范没有额外限制标题区域、配色、材质、底板、光效或装饰。

任一字体项失败即判定 Phase 1 主标题不通过：先重写字体提示词并重新生成或局部编辑，只展示通过本清单的候选；不得把字体问题带入 Phase 2。
