# Seated host scale and bottom-filled table

Apply these defaults from the first Phase 1 direction whenever a seated presenter and foreground table are required. Explicit task-specific pose, placement, or framing overrides only the affected attributes. Do not add a host or table to tasks that do not call for them.

When bundled, inspect `assets/composition-reference/seated-host-bottom-fill.jpg` as an optional composition-only reference: the user corrected the presenter scale, lowered its position, and extended the desk through the canvas bottom. Borrow proportions and spatial relationships; never borrow its campaign, copy, person identity, palette, room, or visible manual-paste seams for another brief. If the image is absent from a repository/export, use the normalized landmark table below and current user-supplied references as the complete composition specification. Do not block generation, invent the missing image, or substitute an unrelated person or room.

## Normalized 9:16 composition

Measure x as fraction of width and y as fraction of height, from top left. Treat ranges as practical targets rather than distortion instructions.

| Landmark | Default target |
| --- | --- |
| Host center axis | x = 0.50, frontal head and torso |
| Crown of hair | y = 0.28–0.32 |
| Head including hair | width = 0.26–0.30 of canvas |
| Eyes | y approximately 0.37–0.40 |
| Upper body including arms | x approximately 0.21–0.79, width = 0.55–0.60 |
| Hands on tabletop | y approximately 0.64–0.69 |
| Back edge of tabletop | y approximately 0.66–0.69 |
| Front edge of tabletop | y approximately 0.74–0.78 |
| Table front/apron | continuous full-width foreground through y = 1.00 and beyond the crop |

Keep natural head/body proportions, relaxed shoulders, and convincing elbows/wrists and tabletop contact. Enlarge the entire host proportionally; do not enlarge only the face. The presenter must read as a close conversational livestream host centered in the lower-middle, not a small person displayed in a distant room. Leave comfortable air between the title/subtitle and crown without pushing the host upward.

Extend the foreground table to both side edges and below the bottom edge. Crop the desk naturally, so its complete furniture silhouette, feet, and bottom edge are not visible. Do not show a floor strip, under-table gap, pedestal stage, or empty margin beneath it. Continue designed tabletop, front materials, reflections, and supports naturally; never fill with a stretched image strip. Keep the front clean unless copy is explicitly requested.

When large floor visibility is required, show floor behind and to both sides of the host, above the tabletop. Do not shrink the host or raise the desk to reveal floor beneath the foreground table. Keep known platform UI clearance for face, hands, product, and copy; a blank desk front may extend behind platform UI.

## Phase 1 pass/fail

Check all initial alternatives at phone size: host head/body scale, lower-middle placement, natural anatomy, table-to-hand contact, both lateral table bleeds, bottom coverage, and floor distribution. Reject a distant small host, a complete desk floating above the bottom, or any visible floor below the desk. If the user supplies a manual composition, regenerate a coherent whole image with ImageGen using it as layout authority; remove paste seams, duplicate bands, and inconsistent lighting without changing accepted relationships. Defer production separation until the full-image approvals.
