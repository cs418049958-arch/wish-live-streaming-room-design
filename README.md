# Wish 直播间设计 GPT-6

将直播间策划稿、PPT 草稿、产品图、人物参考和视觉参考，转化为完整的 **9:16 电商直播间视觉**，并在定稿后制作可还原画面的生产素材。

**执行顺序：00 解读策划 → 01 用 ImageGen 生成直播间整图方案 → 02 用 ImageGen 生成贴片设计板 → 03 用 ImageGen 生成加入贴片的完整预览 → 04 全部确认后拆分、回拼检查、交付。**

前三个制作阶段都以完整画面或完整设计板审稿。**背景、标题、展台、人物和贴片的生产拆分，统一放在第 04 阶段。** 回拼用于定稿后的生产校验；已确认的 ImageGen 完整画面始终保留为对照母版。

## 最新步骤与顺序

| 顺序 | 执行内容 | 输出及确认 |
| --- | --- | --- |
| **00｜解读策划与参考** | 核对标题、文案、数据、产品数量、人物、场景、展台、贴片分组及安全区，明确各参考图的作用。最新用户标注优先。 | 确定本次视觉方向与内容要求。 |
| **01｜直播间整图方案** | 直接用 ImageGen 生成完整 9:16 空间构图，包含背景、顶部标题，以及明确要求的主播、展台和实体产品；普通营销贴片留到下一阶段。按用户要求生成方案数量。 | `01-空间构图预览.jpg`；选择、修改并确认空间构图。 |
| **02｜贴片设计方案** | 先整理贴片数量、文案、顺序和组合关系，再以结构母板为内容依据、已确认直播间为风格依据，用 ImageGen 生成完整 16:9 贴片设计板。 | `02-贴片结构母板-16x9.jpg`、`02-贴片设计母板-16x9.jpg`；确认贴片设计。 |
| **03｜完整直播间预览** | 用 ImageGen 编辑已确认的第 01 阶段整图，加入已确认贴片；调整位置、大小、层级和遮挡，保留已通过的背景、标题、人物与展台。 | `03-完整直播间预览.jpg`；确认整张画面及贴片位置。 |
| **04｜拆分、校验与交付** | 三次确认完成后，从最终整图拆出生产素材，修补被遮挡的背景；按定稿坐标回拼，与保持不变的定稿母版对照，检查透明通道、边缘、文字、位置和缺失素材。 | 校验通过后交付背景、透明 PNG 素材及定稿预览。 |

第 01、02、03 阶段各有一次确认。修改已确认的上游内容后，重新检查并确认受影响的后续画面。前三阶段的局部修改仍通过整图编辑或必要的准确文字校正完成，生产抠图、透明素材、定位层和清单均在第 04 阶段制作。

## 首轮人物与展台构图

以下默认值用于明确要求“坐姿主播＋前景桌子”的任务，用户当次构图要求优先：

| 构图要素 | 默认要求 |
| --- | --- |
| 主播位置 | 正面、居中、靠近镜头，整体放大并位于画面中下部。 |
| 头顶位置 | 约画面高度的 28%–32%。 |
| 头部含头发宽度 | 约画面宽度的 26%–30%。 |
| 上半身含手臂宽度 | 约画面宽度的 55%–60%；整体等比调整，保持自然人体比例。 |
| 手与桌面 | 双手自然接触桌面；桌面后沿约在画面高度的 66%–69%。 |
| 桌子铺底 | 桌子左右铺满，桌身持续延伸出画面底边。 |
| 地板展示 | 地板主要保留在人物身后和两侧、桌面以上区域。 |
| 禁止情况 | 人物过小或位置过高、桌底露出一条地板、桌子悬空、完整桌脚挤在画面内。 |

完整比例和检查项见 [坐姿主播与桌子构图规范](references/seated-host-composition.md)。规范内的参考图片为可选补充；仓库未附该图片时，按文字比例表及当次用户参考执行。

## 贴片画布、色块与间距

以下规则从第 02 阶段首次出图开始执行：

- **画布纯白：** 整张 16:9 设计板及贴片间空隙统一为 `#FFFFFF`，无米白偏色、渐变、纹理、场景或共用地面阴影。
- **贴片保留色块：** 贴片本身根据直播间风格设计饱满的背景色块、宽标题底托与材质层次。画布白底不等于所有贴片内部都做白，也不能退化成细边框。
- **每个贴片留足间距：** 独立贴片之间及画布边缘，至少保留画布短边的 **4.5%**；1920 × 1080 下约为 **48px**，建议 48–64px 或更大。
- **按最外沿计算：** 间距包含文字、边框、阴影和装饰的完整范围。各组之间不重叠、不粘连、不跨组连接，便于后续单独框选抠图。
- **组合关系清晰：** 明确组合的模块作为一组；每张独立报告卡各自留白，不挤成一排相连的边框。
- **证书位置留白：** 要求自行放证书时，报告内部保留白色竖版空白区；外框、标题和底托仍可有颜色，不虚构报告、印章或结论。
- **保持可读：** 出图前调整排布和比例，保留间距与文字可读性。出图后检查完整轮廓，间距不足则修改整张设计板。

第 02 阶段提供白底设计板；第 04 阶段交付的透明素材必须带真实 Alpha 通道，两者用途不同。

## 定稿后的生产输出

| 文件 | 用途与规格 |
| --- | --- |
| `背景.jpg` | 1080 × 1920 纯场景，移除标题、人物、展台和贴片后自然修补。 |
| `顶部大标题.png` | 1080 × 1920 透明定位图层，包含标题及其所属的副标题、Logo、底托和装饰。 |
| `前景展台+产品.png` | 存在展台或实体产品时输出，1080 × 1920 透明定位图层。 |
| `贴片合集-16x9.png` | 1920 × 1080 透明贴片合集，各素材完整、独立且留有透明间隙。 |
| `03-完整直播间预览.jpg` | 已确认的 ImageGen 完整定稿母版，保留原样作为校验依据。 |
| `work/贴片定位层-9x16.png` | 1080 × 1920 透明定位层，用于复现最终贴片坐标。 |
| `work/贴片清单.json` | 各贴片的素材范围和最终定位信息。 |
| `work/人物预览层.png` | 画面含生成主播时保留，用于内部回拼校验。 |
| `work/图层回拼.png`、`work/差异图.png` | 从生产素材回拼得到的检查图及其与定稿母版的差异图。 |

生成主播默认用于构图预览；只有明确要求固定虚拟主播时，才交付 `人物.png`。产品默认不摆放，主播也不自行添加，均以策划文字或用户明确要求为准。贴片内的说明性产品图属于该贴片，不自动转为展台上的实体产品。

## 使用方式

在 ChatGPT / Codex 中调用：

```text
@Wish 直播间设计 GPT-6
这是本次直播间策划稿和视觉参考。
请用 ImageGen 直接生成三张完整的 9:16 第一阶段方案给我选择。
```

第一阶段确认后，可继续要求：

```text
根据已确认直播间的风格，生成三张不同的 16:9 贴片设计板。
画布纯白，每个独立贴片留足抠图间距，贴片本身保留饱满背景色块。
报告内部留白，我后续自行加入证书。
```

贴片设计确认后生成完整直播间预览；完整画面确认后开始生产拆分与校验。
