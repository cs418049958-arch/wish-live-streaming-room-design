# Wish 直播间设计 GPT-6

将直播间策划稿、PPT 草稿、产品图、人物参考和视觉参考，转化为高完成度的 **9:16 电商直播间视觉**。

这个 Skill 采用四阶段流程，把背景空间、标题人物、前景展台产品、营销贴片与生产分层拆开处理。前三阶段分别确认，生产阶段校验交付；确认前先从实际图层回拼预览，确保最终文件能够还原已确认的画面。



## 核心能力

- 深度读取策划稿、标注、产品图、人物参考与风格参考
- 先锁定背景、标题、人物、前景展台和产品，再设计营销贴片
- 通过 16:9 贴片母板统一贴片家族的造型、材质与视觉层级
- 严格按照策划稿坐标合成完整 9:16 直播间预览
- 输出纯背景、透明贴片、透明前景展台＋产品、透明顶部标题
- 校验透明通道、图层尺寸、坐标漂移、裁切和图层污染
- 根据贴片清单校验素材与定位层，并输出回拼预览和差异报告
- 针对“除螨喷雾直播间”启用专项标题字体规则

## 四阶段工作流

| 阶段 | 确认内容 | 主要输出 |
|---|---|---|
| 01 空间骨架 | 背景、标题，以及策划明确要求的人物、前景展台与产品 | `01-空间构图预览.jpg` |
| 02 贴片设计 | 贴片数量、文案、组合关系、统一风格 | `02-贴片设计母板-16x9.jpg` |
| 03 完整合成 | 贴片位置、比例、层级与整体效果 | `03-完整直播间预览.jpg` |
| 04 生产拆分 | 透明通道、尺寸、坐标与图层归属 | 生产图层文件 |

前三阶段依次确认，未确认前不会提前进入下一阶段，也不会在后续阶段静默修改已经通过的设计。第四阶段完成生产图层与回拼校验后交付。

## 生产输出

- `背景.jpg`：1080 × 1920 纯场景
- `前景展台+产品.png`：有展台或产品时输出，1080 × 1920 透明定位图层
- `顶部大标题.png`：1080 × 1920 透明定位图层
- `贴片合集-16x9.png`：1920 × 1080 透明贴片合集
- `work/贴片定位层-9x16.png`：1080 × 1920 透明定位参考
- `03-完整直播间预览.jpg`：从实际图层合成的完整预览
- `work/贴片清单.json`：贴片素材与定位信息，用于内部校验

生成的主播默认用于构图预览；只有明确需要固定虚拟主播时，才交付 `人物.png`。

## 适用场景

- 抖音、快手等 9:16 竖版电商直播间
- 新品发布、节日大促、品牌专场、日销直播间
- 从运营策划截图或 PPT 草稿快速建立视觉方向
- 需要分阶段审稿、减少反复修改的直播间设计项目
- 需要后续 Photoshop、直播软件或搭建团队继续使用的生产分层

## 使用方式

在 ChatGPT / Codex 中调用：

```text
@Wish 直播间设计 GPT-6
这是本次直播间策划稿、产品图和视觉参考，请先生成三个第一阶段方向给我选择。
```

确认第一阶段后，Skill 会依次推进贴片设计、完整合成与生产拆分。

## 设计原则

- 策划关系优先于风格参考
- 最新用户标注优先于旧版本说明
- 一次只解决当前阶段的问题
- 产品数量、包装、位置和层级必须准确
- 默认不摆放实体产品，也不自行添加主播；按策划文字或用户明确要求加入
- 不接受乱码中文、模板化白卡、默认办公字体和伪透明底
- 拆分阶段只做生产处理，不重新设计已确认画面
